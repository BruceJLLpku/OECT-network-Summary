OECT 网络设计文献库

把散落在各处的交联网络 / 双网络 OECT 文献，收成一张可以指导配方的表。

这个站按设计方案而不是按年份组织文献：交联密度怎么调、亲水 OMIEC 该接疏水交联剂还是亲水网络、 疏水半导体要不要拖一条亲水网络、溶胀到底怎样改写电学……每个文件夹是一种解法。 打开任意一篇，先看它用了什么结构，再看形貌上发生了什么，最后看电学数字怎么变—— 并把这条因果链写清楚，方便你决定要不要抄。

怎么用

按设计方案浏览。左侧选一类，页面顶部是该方案的【总览设计规则】——这类文献共同回答的问题、可调的结构旋钮、形貌与电学上的共性后果。往下是逐篇精读卡片。

按关键词搜。点顶部搜索框或按 Ctrl K，可搜半导体名、交联剂（GOPS / DtFDA / PEGDA…）、材料缩写、结论词。多个关键词用空格分隔，需同时命中。

读一篇文献。卡片折叠摘要，展开后依次是：结构配方 → OECT 条件（电解液 / 溶胀 / 电极）→ 各状态的电学与形貌 → 因果链 → 可借鉴点与局限。文末可下载原文 PDF。

缺项说明。原文没写的数字或材料一律标「未报道」，不靠常识补全。比例若为换算所得会标注「推算」。

组内学术交流使用。原文版权归各出版社与作者所有；本站仅做结构化精读与索引，请勿用于商业用途。
